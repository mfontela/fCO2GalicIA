# pCO2GalicIA

---

## Overview
This repository contains the code and workflows used to estimate deltafCO₂ in the NW Iberian upwelling system. 

---

## Key Features
- Machine‑learning ensemble integrating three algorithms: Support Vector Regression (SVR), Extreme Gradient Boost (XGBoost) and Random Forest (RF) to increase predictive robustness.
- Fully reproducible workflow: preprocessing, model training, validation, and ensemble aggregation.
